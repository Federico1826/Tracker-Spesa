# Tracker Spese 💰

Tracker Spese è una mini web app sviluppata in JavaScript che permette di gestire e monitorare le spese quotidiane in modo semplice e intuitivo.

L’app consente di inserire spese, filtrarle per categoria e mese, visualizzare il totale e analizzare i dati tramite un grafico interattivo.

---

## 🚀 Funzionalità

- Aggiunta di una spesa con:
  - descrizione
  - importo
  - categoria
  - data
- Modifica ed eliminazione delle spese
- Filtro per:
  - categoria
  - mese
- Calcolo dinamico del totale in base ai filtri selezionati
- Grafico a torta delle spese per categoria
- Reset dei filtri
- Salvataggio automatico dei dati tramite **LocalStorage**

---

## 🛠️ Tecnologie utilizzate

- HTML5
- CSS3
- JavaScript (Vanilla)
- Chart.js
- LocalStorage API
